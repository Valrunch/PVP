PvP datapack for my Minecraft server.

Quick usage:
- /trigger pvp.trigger set 1 or /trigger pvp.trigger add 1
- a duel request opens a proper Inventory Menu if Inventory Menu is installed
- the pack keeps survival inventory separate (via dimension-based cleanup / restore flow)

Notes:
- trigger objectives are auto-enabled for players to keep the flow easier and more intuitive
- this datapack is designed for Fabric + Inventory Menu on 1.21.1
